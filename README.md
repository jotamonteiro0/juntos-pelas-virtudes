## 📋 Sobre o Projeto

Este repositório contém o código-fonte do site oficial da chapa **Juntos pelas Virtudes, Unidos pelo Piauí**, desenvolvido para apresentar os candidatos, propostas e o plano de gestão para o Gabinete Estadual da Ordem DeMolay do Piauí — Gestão 2026/2027.

---

## 📁 Estrutura

```
├── index.html          # Página principal
├── projetos.html       # Projetos e ações da gestão
├── joaomce.html        # Biografia do MCE
├── pedromcea.html      # Biografia do MCEA
├── plano.pdf           # Plano de Gestão completo
├── css/
│   └── style.css       # Estilos globais
├── js/
│   └── main.js         # Scripts
└── assets/
    └── images/         # Imagens e material gráfico
```

## 🚀 Rodando localmente

```bash
git clone https://github.com/jotamonteiro0/juntos-pelas-virtudes.git
cd juntos-pelas-virtudes
# Abra o index.html no navegador ou use um servidor local:
npx live-server
```
